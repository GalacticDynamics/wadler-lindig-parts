# Tutorials

Lessons for people who have not used this package before. Work through them in
order at a keyboard; each one ends with something you built and can re-run.

If you already know what you want to accomplish, the
[how-to guides](../how-to/index.md) are shorter and assume you do.

Everything here runs on a laptop with nothing installed but the package. No
account, no key, no network beyond `pip install`.

## The sequence

1. [Make your first formattable type](your-first-formattable-type.md) — build a
   `Duration` that prints as text, HTML and LaTeX from one method you write.
2. [Teach the grammar a new word](teach-the-grammar-a-new-word.md) — add
   `total` to the spec vocabulary and watch it compose with markups you never
   touched.
